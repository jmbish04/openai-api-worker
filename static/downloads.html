Each download includes a helper that ensures a local .env file contains WORKER_URL and WORKER_API_KEY. The default URL is populated for you—just edit the key.

Place the downloaded script in a project folder, run it with Python 3.9+, and install dependencies with pip install requests. The advanced client also uses the sqlite3 module, which is part of the Python standard library and does not require installation.
